## Research Focus

This thesis investigates the relationship between immune system aging and cellular senescence using single-cell RNA sequencing data from the Tabula Muris Senis (TMS) project.

### Key Research Areas

1. **T Cell Aging Dynamics**
   - CD4+ T cell subset changes across age groups
   - Identification of age-associated T cell populations
   - Cross-species comparison (mouse and human)

2. **Cellular Senescence**
   - Senescence marker analysis across tissues
   - Age-dependent senescence patterns
   - Senescence-associated secretory phenotype (SASP)

3. **Multi-Tissue Analysis**
   - Analysis of 16 different tissues
   - Tissue-specific aging signatures
   - Integrated cross-tissue comparisons

4. **Exceptional Aging**
   - Supercentenarians immune profiling
   - Comparison with normal aging patterns
   - Identification of protective mechanisms
