# Project Summary - Immunaging and Cellular Senescence

## 🎯 Research Overview

This project investigates how the immune system changes with aging and how these changes relate to cellular senescence, using cutting-edge single-cell RNA sequencing technology.

## 📋 The Problem

Aging is associated with:
- **Immune system decline** (immunosenescence)
- **Increased cellular senescence** (cells stopping division)
- **Higher disease susceptibility** (cancer, infections, chronic diseases)

**Key Question**: How do immune cell changes with age contribute to or result from cellular senescence?

## 🔬 Research Approach

### Data Source
- **Tabula Muris Senis (TMS)** - Comprehensive single-cell atlas of aging mice
- **16 tissues** analyzed across the entire body
- **Age range**: 1 month (young) to 30 months (old)
- **~100,000+ cells** analyzed

### Analysis Strategy
1. **Multi-tissue integration** - Combined data from all tissues
2. **T cell focus** - Deep analysis of T cell populations
3. **Senescence mapping** - Identified senescent cells across tissues
4. **Cross-species comparison** - Compared mouse findings to human data
5. **Exceptional aging** - Analyzed supercentenarians (100+ years old)

## 🎯 Key Findings

### 1. T Cell Aging Dynamics
- **CD4+ T cell diversification** with age
- **Novel CD4+ subsets** identified in aged mice
- **Age-associated cytotoxic CD4+ T cells** discovered
- **Regulatory T cell shifts** between young and old

### 2. Senescence Patterns
- **Tissue-specific senescence signatures** identified
- **Age-dependent senescence accumulation** across tissues
- **Conserved senescence markers** (p16, p21, SASP genes)
- **Novel senescence-associated genes** discovered

### 3. Cross-Tissue Insights
- **Shared aging pathways** across different tissues
- **Tissue-specific immune aging** patterns
- **Organ-specific senescence** characteristics

### 4. Human Relevance
- **Conserved aging signatures** between mouse and human
- **Supercentenarian protective mechanisms** identified
- **Translational potential** for human aging interventions
